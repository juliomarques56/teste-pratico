# Teste Prático - Engenheiro de Qualidade Sênior

## Objetivo
Avaliar a habilidade do candidato em configurar um ambiente de testes, utilizar Git e aplicar conhecimentos em Cypress ou Appium.

## Cenário
**Aplicativo:** Acessar a landing page [Meus Empréstimos - PicPay](https://meus-emprestimos.picpay.com/) e interagir com o formulário de login.

## Tarefa
Criar um teste automatizado que:
1. Abra um navegador de sua escolha.
2. Acesse o site e navegue na área não logada.
3. Interaja com o campo CPF.
4. Verifique os retornos apresentandos pelo sistema.
6. Gere evidências das navegações.

## Instruções para o Candidato
1. **Fork este repositório:** O candidato deverá criar um fork deste repositório GitHub.
2. **Clone o seu fork:** O candidato deverá configurar seu ambiente de desenvolvimento com as ferramentas necessárias para executar os testes (Node.js, npm, etc.).
3. **Criação do teste:** O candidato deverá implementar o cenário descrito acima.
4. **Execução do teste:** O candidato deverá executar o teste e verificar se ele passa.
5. **Implemente o teste:** Siga as instruções acima para criar o teste automatizado.
7. **Faça um commit e push:** O candidato deverá commitar as alterações e fazer um push para o seu fork.
8. **Envio do link:** O candidato deverá enviar o link do seu fork para que a equipe possa avaliar o código.
9. **README:** Um arquivo README com instruções detalhadas sobre como configurar o ambiente, executar os testes e enviar a solução.

## Dicas
- Utilize comentários para explicar seu código.
- Siga boas práticas de desenvolvimento de testes.
- Divida o teste em etapas menores para facilitar a leitura e manutenção.

## Critérios de Avaliação
Serão considerados os seguintes aspectos:
- **Correção:** O teste executa corretamente o cenário proposto?
- **Qualidade do código:** O código está bem estruturado, comentado e segue boas práticas?
- **Uso do framework:** O candidato demonstra conhecimento em Cypress ou Appium?
- **Criatividade:** Apresenta soluções inovadoras ou alternativas?

## Observações
- O nível de complexidade pode ser adaptado conforme o perfil do candidato.
- Outros cenários podem ser adicionados para avaliar diferentes habilidades, como testes de API ou testes de performance.
- Ferramentas de code review podem ser utilizadas para facilitar a avaliação.

Com este teste, buscamos avaliar com precisão as habilidades técnicas e a capacidade de resolução de problemas dos candidatos.
